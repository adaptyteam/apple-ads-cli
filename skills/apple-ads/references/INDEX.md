# Routing — operating an account

One row, one file. Read only the file the row names, then come back to `SKILL.md` for syntax.

| The user is asking | Open |
|---|---|
| Is the account set up, can I run anything | `playbooks/preflight.md` |
| What changed last week / last month and what should happen next | `playbooks/weekly-review.md` |
| Which keywords or campaigns actually pay back | `playbooks/cohort-roas.md` |
| Turn search terms into verified Exact owners and cross-negatives | `playbooks/search-term-harvesting.md` |
| Raise, cut, keep or pause keyword bids by an explicit value rule | `playbooks/bid-optimization.md` |
| Move budget between campaigns | `playbooks/budget-reallocation.md` |
| Launch a new campaign | `playbooks/campaign-launch.md` |
| Load a keyword list into an ad group | `playbooks/keyword-load.md` |
| Mine irrelevant traffic and add the narrowest safe negatives | `playbooks/negative-keyword-hygiene.md` |
| Route a keyword intent to an existing custom product page and ad | `playbooks/creative-setup.md` |
| Find per-app, per-country keyword opportunities from competitors | `playbooks/keyword-opportunity.md` |
| Spend is running away, stop it | `playbooks/runaway-spend.md` |
| Set up or review a rule automation | `playbooks/automation-rules.md` |
| Why is this ad not running | `SKILL.md`, workflow 8 — no playbook needed |

Command syntax is never in a playbook. It lives in `asa-management.md` and `asa-metrics.md`.

Broad account health and live structure diagnostics belong to the read-only `apple-ads-audit`
skill, not this operator index.

`playbooks/competitor-check.md` is a compatibility redirect for old external links. New routing
must open `playbooks/keyword-opportunity.md` directly.
